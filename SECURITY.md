# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security problem. Use GitHub private
vulnerability reporting instead:
https://github.com/azrtydxb/momo/security/advisories/new

We aim to acknowledge every report within 7 days.

## Supported versions

| Version        | Supported |
| -------------- | --------- |
| Latest minor   | Yes       |
| Older versions | No        |
