# M4: Ecosystem, adoption, performance, docs

Status: open
Created: 2026-11-04

## Goal

Teams can adopt Momo from GORM, Ent or Bun: ecosystem generators, importers and migration guides exist; reproducible benchmarks against handwritten pgx/sql, GORM, Ent and Bun are published without unproven claims; the versioned docs site for AI coders is live and v0.1.0 can be released.

Epics, in execution order: `momo-10-ecosystem-generators`, `momo-11-adoption`, `momo-12-performance`, `momo-13-docs-release`.
