# Sprint 7: finish every open backlog story, auditing each against the real code first

Status: active
Created: 2026-11-10

## Goal

Close the backlog that the M1 to M4 milestones still carry. Many of these stories date from the first plan, and later sprints may already have built them under other names. So each story is first checked against the code on main. A story the code already satisfies is closed with evidence from CI. One that it does not is built, tested on CI and reviewed. One that no longer fits the product is carried with a reason. At the end of the sprint every story is either done or carried with a stated reason.
