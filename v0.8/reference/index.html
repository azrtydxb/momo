    API reference¶

    Every exported identifier of the core package and the feature packages, with the first sentence of its doc comment. Methods are listed as pkg.Type.Method. The full text of each comment is on pkg.go.dev.

    momo¶

    Import path: github.com/azrtydxb/momo

    Identifier Kind Synopsis
    momo.Agg type Agg is a typed aggregate expression such as COUNT(*) or SUM(col).
    momo.Agg.As method As names the aggregate in a select list: SUM(col) AS name.
    momo.Agg.Filter method Filter restricts the rows the aggregate sees: COUNT(*) FILTER (WHERE p).
    momo.Agg.Over method Over turns an aggregate into a window function: SUM(x) OVER (...).
    momo.Aliased type Aliased is a select-list item "expr AS alias".
    momo.Aliased.AppendSQL method AppendSQL writes the expression and its alias to b.
    momo.Aliased.Asc method Asc orders by the alias ascending.
    momo.Aliased.Desc method Desc orders by the alias descending.
    momo.Aliased.Ref method Ref is the typed column through which an outer query reads this alias from a subquery (FromSubquery alias) or CTE (name) called source.
    momo.AllowStaleReads func AllowStaleReads returns a context that opts reads of a Replica handle back to the replica even after a write in the same unit of work.
    momo.Allowlist type Allowlist maps external names to typed column descriptors.
    momo.Allowlist.Column method Column returns the descriptor for name, or a *Error with Kind ErrValidation.
    momo.And func And joins predicates with AND; an empty And is true.
    momo.ArrayOf func ArrayOf is the array constructor ARRAY[e1, e2, ...] of the element expressions, an Expression[[]T].
    momo.ArraySubquery func ArraySubquery is ARRAY(subquery): the rows of a one-column subquery collected into an array, an Expression[[]T] where T is the Go type of that column.
    momo.As func As aliases an expression in a select list: expr AS alias.
    momo.Asc func Asc orders by an arbitrary expression ascending.
    momo.Assignment type Assignment is one explicit column write.
    momo.Assignment.ColumnName method ColumnName returns the assigned column.
    momo.Association type Association is one relation listed for CreateGraph.
    momo.Avg func Avg is AVG(expr) as float64.
    momo.Batcher type Batcher is implemented by drivers that send several statements in one round trip.
    momo.BatcherOf func BatcherOf returns the Batcher behind q: the driver for a *DB, the transaction for a *Tx.
    momo.Batches func Batches visits every row sq matches in batches of at most n rows, in primary-key order, calling fn for each batch.
    momo.BelongsTo const BelongsTo has its foreign key on the parent; the child is matched by its key.
    momo.Builder type Builder accumulates SQL text and bind arguments for one statement.
    momo.Builder.AppendFilter method AppendFilter writes " FILTER (WHERE p)" for an aggregate call that was just rendered.
    momo.Builder.Arg method Arg appends a bind placeholder and records v as its argument.
    momo.Builder.ArgFor method ArgFor binds v like Arg and records it as sensitive when flags carries FlagSensitive, so QueryEvent.Args shows RedactedArg instead of the value.
    momo.Builder.Args method Args returns the bind arguments built so far.
    momo.Builder.Dialect method Dialect returns the dialect being rendered.
    momo.Builder.Err method Err returns the first build error.
    momo.Builder.ExprFor method ExprFor renders e with every argument it binds recorded as sensitive when flags carries FlagSensitive, for an expression compared with or assigned to such a column.
    momo.Builder.Ident method Ident appends a quoted identifier.
    momo.Builder.MarkSensitive method MarkSensitive records that the expression being rendered read a sensitive column, so an enclosing predicate that compares it masks its other operands in hook events.
    momo.Builder.QualifiedIdent method QualifiedIdent appends qualifier.name, both quoted.
    momo.Builder.RenderSensitive method RenderSensitive renders e and returns flags with FlagSensitive added when e read a sensitive column.
    momo.Builder.SetErr method SetErr records the first build error; rendering continues but the statement will not be executed.
    momo.Builder.String method String returns the SQL text built so far.
    momo.Builder.Unsupported method Unsupported records an ErrUnsupported build error for feature, naming the dialect being rendered.
    momo.Builder.WriteByte method WriteByte appends a trusted SQL byte.
    momo.Builder.WriteString method WriteString appends trusted SQL text.
    momo.BulkUpdate func BulkUpdate updates rows of T from a list of rows keyed by key.
    momo.CTE func CTE references a common table expression (or any table not described by a model) by name.
    momo.Capabilities type Capabilities describes what a driver can execute beyond the dialect.
    momo.CapabilityReporter type CapabilityReporter is implemented by drivers that report driver-level capabilities.
    momo.Coalesce func Coalesce returns the first non-NULL argument.

    momo.Column.SetDefault method SetDefault assigns the column's database default.

    momo.Column.SetExpr method SetExpr assigns an expression.

    momo.ColumnNamer type ColumnNamer is implemented by Rows that can report the names of their result columns, in order, as the database reports them.
    momo.ColumnOf func ColumnOf declares a typed column of an ad-hoc source (CTE, subquery alias).
    momo.ColumnRef type ColumnRef is an untyped reference to a column of a table source.
    momo.ColumnRows type ColumnRows is the cursor RawRows returns: a Rows that also names its result columns.
    momo.Compilable type Compilable is a statement that renders to SQL without running it.
    momo.Compiled type Compiled is a rendered statement ready for inspection or execution.
    momo.Compiled.String method String returns the SQL text.
    momo.Config type Config is the receiver of a model's MomoConfig companion method.
    momo.Config.Check method Check declares a named check constraint.
    momo.Config.Collate method Collate sets a column collation.

    momo.Config.Default method Default sets a column default expression.
    momo.Config.Enum method Enum declares a named enum type with its values.
    momo.Config.FKName method FKName names the foreign key constraint of the belongs_to relation whose key field is field, for a name other than the derived __fkey (for example _fkey1 on a partitioned table). reference returned by Column.Excluded..
    momo.Config.ForeignKey method ForeignKey declares a named foreign key over one or more fields of the model: cols is a []any literal of field references, refTable the referenced table and refColumns its columns, which must be its primary key or the columns of a unique constraint or unique index on it.
    momo.Config.Function method Function declares a function.
    momo.Config.Generated method Generated declares a column as stored generated: GENERATED ALWAYS AS (expr) STORED.
    momo.Config.GeneratedVirtual method GeneratedVirtual declares a column as VIRTUAL generated: GENERATED ALWAYS AS (expr) VIRTUAL, computed on read.
    momo.Config.IDGen method IDGen declares a Go-side id generator for a string field: an insert fills the field when it holds the zero value.
    momo.Config.Index method Index declares a non-unique index over the given field references.
    momo.Config.IndexExpr method IndexExpr declares an expression index.
    momo.Config.Partition method Partition declares the table's partitioning.
    momo.Config.PartitionOf method PartitionOf declares the table as a partition of a parent.
    momo.Config.Policy method Policy declares a row-level security policy.
    momo.Config.PrimaryKey method PrimaryKey orders the columns of a composite primary key, for a key whose column order differs from the field order (the order is the btree order that lookups rely on).
    momo.Config.RLS method RLS declares the table's row-level security flags.
    momo.Config.Trigger method Trigger declares a trigger.
    momo.Config.Unique method Unique declares a unique index over the given field references.
    momo.Config.View method View declares a view or materialized view.
    momo.ConflictQuery type ConflictQuery is an INSERT awaiting its ON CONFLICT action.
    momo.ConflictQuery.DoNothing method DoNothing skips rows that conflict.
    momo.ConflictQuery.DoUpdate method DoUpdate updates the existing row on conflict.
    momo.ConflictQuery.Where method Where adds predicates to the conflict target, rendered as ON CONFLICT (cols) WHERE .
    momo.ContainsLiteral func ContainsLiteral matches rows whose string expression contains s literally.
    momo.Copier type Copier is implemented by drivers with a native bulk-copy path.
    momo.CopierOf func CopierOf returns the Copier behind q: the driver for a *DB, the transaction for a *Tx.
    momo.CountAll func CountAll is COUNT(*).
    momo.CountDistinct func CountDistinct is COUNT(DISTINCT expr).
    momo.CountOf func CountOf is COUNT(expr), which skips NULLs.
    momo.CreateGraph func CreateGraph inserts p and the children of the listed relations in one transaction.
    momo.CreateOnlyColumn type CreateOnlyColumn is the descriptor of a column writable in INSERT only.
    momo.CreateOnlyColumn.As method As returns the same column qualified by a table alias.
    momo.CreateOnlyColumn.Excluded method Excluded is the value proposed for insertion, for an upsert condition.
    momo.CreateOnlyColumn.Set method Set assigns v on insert.
    momo.CreateOnlyVectorColumn type CreateOnlyVectorColumn is a vector column writable in INSERT only.
    momo.CreateOnlyVectorColumn.As method As returns the same column qualified by a table alias.
    momo.CreateOnlyVectorColumn.Set method Set assigns v on insert; only Insert accepts the result.
    momo.CurrentRow func CurrentRow is CURRENT ROW.
    momo.DB type DB is a Momo handle over a driver.
    momo.DB.AdoptTx method AdoptTx binds a Tx to dtx, a driver transaction the caller already began and keeps ownership of.
    momo.DB.Begin method Begin starts an explicit transaction.
    momo.DB.Dialect method Dialect returns the dialect of the connection.

    momo.DB.OnConn method OnConn returns a handle whose statements all run on pc, a connection pinned with Pinner.Pin.
    momo.DB.Replica method Replica returns a read handle whose plain reads go to replica i, unless the context is a unit of work that has written: then reads go to the primary.
    momo.DB.Tx method Tx runs fn in a transaction.

    momo.DefaultHybridRRFK const DefaultHybridRRFK is the rank constant used when HybridSpec.RRFK is zero (Cormack, Clarke and Buettcher, 2009).
    momo.DefaultQueries func DefaultQueries returns the process-wide registry that RegisterQuery fills.
    momo.Delete func Delete starts a DELETE from T's table.
    momo.DeleteQuery type DeleteQuery builds a DELETE of one model table.
    momo.DeleteQuery.AllRows method AllRows confirms that a DELETE without WHERE is intended.
    momo.DeleteQuery.AppendSQL method AppendSQL renders the statement in parentheses as a WITH clause body.
    momo.DeleteQuery.Exec method Exec runs the DELETE.
    momo.DeleteQuery.Model method Model deletes the row identified by m's primary key.
    momo.DeleteQuery.One method One runs the DELETE and returns the single RETURNING row: ErrNotFound when no row matched and ErrTooManyRows when more than one did.

    momo.DeleteQuery.SQL method SQL renders the statement without executing it.

    momo.DeleteQuery.Where method Where adds predicates combined with AND.
    momo.DeleteQuery.With method With prefixes the statement with a common table expression; see UpdateQuery.With for the allowed bodies and the dialect rules (MariaDB refuses the clause with ErrUnsupported).

    momo.DenseRank func DenseRank is dense_rank(): the rank without gaps.
    momo.Desc func Desc orders by an arbitrary expression descending.

    momo.DirAsc const DirAsc orders by ascending count.
    momo.DirDesc const DirDesc orders by descending count.
    momo.Direction type Direction orders by relation count.
    momo.Discarder type Discarder is implemented by pinned connections that can be thrown away instead of returned to the pool.
    momo.Discriminator type Discriminator restricts a polymorphic has-one/has-many to rows whose type column equals Value.
    momo.Driver type Driver is the connection-adapter contract.
    momo.DriverTx type DriverTx is a driver-level transaction.
    momo.ErrAdoptedTx var ErrAdoptedTx: Commit or Rollback was called on a Tx from DB.AdoptTx.
    momo.ErrBusy var ErrBusy: the database is busy or locked and could not serve the request.
    momo.ErrCanceled var ErrCanceled: a streaming read stopped because its context ended.
    momo.ErrCheckViolation var Sentinel error kinds.
    momo.ErrForeignKeyViolation var Sentinel error kinds.
    momo.ErrInvalidVector var ErrInvalidVector: a vector value failed validation.
    momo.ErrLimitExceeded var ErrLimitExceeded: a configured limit (rows, size, parameters) was exceeded.
    momo.ErrNotFound var ErrNotFound: a single-row operation (One, First, Model update/delete) matched no row.
    momo.ErrNotNullViolation var Sentinel error kinds.
    momo.ErrOptimisticLock var ErrOptimisticLock: an update or delete guarded by an expected version matched no row because the version changed (or the row is gone).
    momo.ErrPinnedBusy var ErrPinnedBusy: PinnedConn.Release was called while a statement was still executing on the connection from another goroutine.
    momo.ErrSerialization var ErrSerialization: the database aborted the transaction because of a serialization failure or deadlock.
    momo.ErrTooManyRows var ErrTooManyRows: One matched more than one row.
    momo.ErrTxDone var ErrTxDone: the transaction was already committed or rolled back.
    momo.ErrUnfilteredMutation var ErrUnfilteredMutation: an UPDATE or DELETE without a WHERE clause was attempted without calling AllRows.
    momo.ErrUniqueViolation var Sentinel error kinds.
    momo.ErrUnsupported var ErrUnsupported: the dialect or driver cannot express the request.
    momo.ErrValidation var ErrValidation: a value failed validation before reaching the database.

    momo.Error.Detail method Detail returns the raw driver detail captured by the classifier (it can quote row values, so handle it as sensitive).
    momo.Error.Error method Error returns the kind, the operation and its identifying fields, followed by the text of the wrapped error.
    momo.Error.Is method Is reports whether target is this error's kind.
    momo.Error.Unwrap method Unwrap returns the underlying error.
    momo.ErrorClassifier type ErrorClassifier converts a raw driver error into a structured *Error when it recognizes it, and returns err unchanged otherwise.
    momo.EscapeLike func EscapeLike escapes %, _ and the escape character ! (each is prefixed with !) so the result matches literally inside a LIKE pattern rendered with ESCAPE '!', which Like, ILike and ContainsLiteral always emit.
    momo.ExcludedExpr type ExcludedExpr is the EXCLUDED.
    momo.ExcludedExpr.AppendSQL method AppendSQL writes the EXCLUDED column reference to b.
    momo.Exec func Exec runs a raw statement.
    momo.Exists func Exists is true when the subquery yields any row.
    momo.Explain func Explain returns the database's plan for the compiled statement c without executing it: EXPLAIN on PostgreSQL, EXPLAIN FORMAT=JSON on MySQL and MariaDB (one text column) and EXPLAIN QUERY PLAN on SQLite.
    momo.ExplainAnalyze func ExplainAnalyze runs c under EXPLAIN (ANALYZE, FORMAT TEXT) and returns the plan with actual timings.
    momo.Expr type Expr is any SQL expression fragment.
    momo.ExprSelect type ExprSelect is a SELECT of explicit expressions that needs no result type: a FROM-less list of values or parameters with an optional WHERE, or a plain SELECT over one source.
    momo.ExprSelect.AppendSQL method AppendSQL renders the select in parentheses, for use as a subquery.
    momo.ExprSelect.CrossJoin method CrossJoin adds a CROSS JOIN, like SelectQuery.CrossJoin.
    momo.ExprSelect.From method From sets the FROM source.
    momo.ExprSelect.GroupBy method GroupBy adds GROUP BY expressions.
    momo.ExprSelect.Having method Having adds HAVING predicates combined with AND.
    momo.ExprSelect.Join method Join adds an INNER JOIN, like SelectQuery.Join.
    momo.ExprSelect.LeftJoin method LeftJoin adds a LEFT JOIN, like SelectQuery.LeftJoin.
    momo.ExprSelect.OrderBy method OrderBy appends ORDER BY items: an Order such as Column.Asc() or any Expression, which orders ascending.
    momo.ExprSelect.Where method Where adds predicates combined with AND.
    momo.Expression type Expression is an Expr whose SQL result type corresponds to the Go type T.
    momo.FieldHook type FieldHook attaches Go-side behavior to one column of Meta[T].
    momo.FieldNamer type FieldNamer names the column of a Go struct field.

    momo.Filter.Predicate method Predicate builds the predicate.
    momo.FilteredAgg type FilteredAgg is an aggregate with a FILTER (WHERE ...) clause, built with Agg.Filter.

    momo.FilteredAgg.As method As names the aggregate in a select list.
    momo.FilteredAgg.Over method Over turns the filtered aggregate into a window function.

    momo.Func func Func is a typed call of the SQL function name.

    momo.IDs func IDs returns the primary-key value of every row sq matches, in the query's order.
    momo.ILike func ILike is PostgreSQL's case-insensitive LIKE.
    momo.Ident func Ident renders name as a quoted identifier in the dialect's style.
    momo.ImmutableColumn type ImmutableColumn is the descriptor of a column that is set on insert and never changed.

    momo.ImmutableColumn.Excluded method Excluded is the value proposed for insertion, for an upsert condition.

    momo.ImmutableVectorColumn.Set method Set assigns v on insert; only Insert accepts the result.
    momo.In func In expands a slice argument into a comma-separated list of bind markers, one per element, for a raw placeholder written inside the parentheses of IN (?).
    momo.IndexOpts type IndexOpts carries the optional parts of an index declaration.
    momo.IndexOpts.Concurrently method Concurrently marks the index to be built concurrently.
    momo.IndexOpts.Desc method Desc marks one indexed field descending.
    momo.IndexOpts.Method method Method sets the index access method.
    momo.IndexOpts.Nulls method Nulls sets NULLS ordering ("first" or "last") for one indexed field.
    momo.IndexOpts.Opclass method Opclass sets the operator class of one indexed field.
    momo.IndexOpts.Unique method Unique makes the index a unique index.
    momo.IndexOpts.Where method Where sets the partial-index predicate.
    momo.IndexOpts.With method With sets one index storage parameter.
    momo.Insert func Insert starts an INSERT for model T.
    momo.InsertAssignment type InsertAssignment is one explicit column write that is valid in an INSERT only.
    momo.InsertAssignment.ColumnName method ColumnName returns the assigned column.

    momo.InsertQuery type InsertQuery builds and runs an INSERT into T's table.
    momo.InsertQuery.AppendSQL method AppendSQL renders the statement in parentheses as a WITH clause body, as SQL would, without running interceptors or the BeforeInsert hook.
    momo.InsertQuery.Copy method Copy streams ms through the driver's Copier (PostgreSQL COPY) and reports the rows written.
    momo.InsertQuery.Exec method Exec runs the statement and reports the rows it inserted.
    momo.InsertQuery.FromSelect method FromSelect makes the rows of a SELECT the source of the INSERT, rendering INSERT INTO t (cols) SELECT ...
    momo.InsertQuery.Model method Model adds one model, writing every column except identity, read-only and omitted columns.
    momo.InsertQuery.Models method Models adds every element of ms as one row of a multi-row VALUES list.
    momo.InsertQuery.Omit method Omit excludes columns from a model insert, leaving their database default.
    momo.InsertQuery.OnConflict method OnConflict starts an ON CONFLICT clause with the given conflict target.
    momo.InsertQuery.One method One runs a single-row INSERT and returns its RETURNING row: ErrNotFound when no row came back (ON CONFLICT DO NOTHING, or a DO UPDATE whose WHERE did not hold) and ErrTooManyRows when more than one did.
    momo.InsertQuery.Returning method Returning appends a RETURNING list; read the rows with Rows.
    momo.InsertQuery.ReturningAll method ReturningAll returns every column mapped by T, in metadata order.
    momo.InsertQuery.Rows method Rows runs the statement and returns its RETURNING rows.
    momo.InsertQuery.SQL method SQL compiles the statement without executing it.

    momo.InsertQuery.Where method Where adds a condition to the DO UPDATE action: the existing row is updated only when the predicates hold, rendered as DO UPDATE SET ...
    momo.InsertQuery.With method With prefixes the INSERT with a common table expression that FromSelect's select can read: WITH x AS (...) INSERT INTO t (cols) SELECT ...
    momo.InsertQuery.WithRecursive method WithRecursive is With for a recursive CTE.
    momo.InsertValue type InsertValue is an explicit column write accepted by Insert.Values: an Assignment, or an InsertAssignment from a create-only or immutable column.
    momo.Interceptor type Interceptor may append predicates or return an error to deny the statement.
    momo.IsBound func IsBound reports whether e is a Go value bound as a parameter by Value, possibly wrapped by Typed.
    momo.JoinSQL func JoinSQL composes raw SQL fragments and their arguments into one expression, the equivalent of Prisma.join: each part is typically SQL("status = ?", s), and the result can be used wherever SQL can.
    momo.JoinTypedSQL func JoinTypedSQL is JoinSQL with a declared result type, for a join used in a projection or a typed comparison, for example a "+" sum of columns.
    momo.Lag func Lag is lag(e, offset): the value offset rows before the current row, NULL when there is none (scan into a nullable destination).
    momo.LagDefault func LagDefault is lag(e, offset, def): def replaces the NULL of a missing row.
    momo.LastValue func LastValue is last_value(e) over the window frame.
    momo.Lateral func Lateral uses a subquery as a LATERAL FROM/JOIN source under alias.
    momo.Lead func Lead is lead(e, offset): the value offset rows after the current row.
